## Доменная область

Это приложение для интернет-магазина 
косметически. Система позволяет пользователям проходить опрос, просматривать 
каталог товаров по категориям, оформлять заказы, отслеживать их статус 
и оставлять отзывы о приобретённых товарах.

## Сущности

### User (Пользователь)
Зарегистрированный пользователь системы. Содержит email, имя и 
хешированный пароль. Может создавать заказы и оставлять отзывы 
на товары.

### Category (Категория)
Категория товаров (например, «Увлажняющие кремы», «Сыворотки», 
«Маски для лица»). Каждый товар принадлежит ровно одной категории.

### Product (Товар)
Товар в каталоге магазина. Имеет название, описание, цену и 
количество на складе. Принадлежит определённой категории.

### Order (Заказ)
Заказ пользователя. Содержит статус жизненного цикла 
(PENDING → CONFIRMED → SHIPPED → DELIVERED или CANCELLED), 
общую стоимость и дату создания.

### OrderItem (Позиция заказа)
Отдельная позиция в заказе. Связывает заказ с конкретным товаром, 
хранит количество единиц и цену на момент оформления.

### Review (Отзыв)
Отзыв пользователя о товаре. Содержит числовую оценку (рейтинг) 
и текстовый комментарий.

## Связи между сущностями

- **User** → **Order**: один ко многим (пользователь может иметь много заказов)
- **User** → **Review**: один ко многим (пользователь может оставить много отзывов)
- **Category** → **Product**: один ко многим (в категории много товаров)
- **Product** → **Review**: один ко многим (у товара много отзывов)
- **Order** → **OrderItem**: один ко многим (в заказе несколько позиций)
- **Product** → **OrderItem**: один ко многим (товар может быть в разных заказах)

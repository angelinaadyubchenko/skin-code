## Проект:
**"My Skin Code" - магазин косметики с функцией подбора средств по типу кожи**

### Краткое описание:
Сайт для  онлайн магазина косметики и персонализированного подбора косметических средств на основе индивидуальных характеристик кожи пользователя. Сервис помогает подобрать оптимальные средства ухода по типу кожи, проблемам и возрасту.
